The Foundations

Era 1: Notepad + Terminal (~2010-2015)

No autocomplete. No syntax highlighting. Just you and the Python docs.

era_1_notepad_terminal.py
# Read CSV manually — no pandas
import csv, os, sys

f = open("data/marketing.csv", "r")
reader = csv.DictReader(f)
data = []
for row in reader:
    data.append(row)
f.close()

# Aggregate manually with dicts
channel_spend = {}
for row in data:
    ch = row["channel"]
    if ch not in channel_spend:
        channel_spend[ch] = 0.0
    channel_spend[ch] += float(row["spend"])
# ... 160 lines total

Era 2: Jupyter Notebooks (2014-present)

Cell-by-cell exploration. Inline plots. Pandas arrives.

era_2_jupyter.ipynb
import pandas as pd
import matplotlib.pyplot as plt
%matplotlib inline

# One line replaces 15
df = pd.read_csv("data/marketing.csv")
df.head()

# One line replaces 30
summary = df.groupby("channel").agg({
    "spend": "sum",
    "revenue": "sum"
})

# See plots inline — instant!
summary.plot(kind="bar")
plt.show()

Tools Get Smarter, Humans Search Better

Era 3: IDE Revolution (2016-present)

VS Code / PyCharm transform the workflow:

• IntelliSense — autocomplete with parameter hints

• Linting — red squiggles catch errors before you run

• Debugger — breakpoints, variable inspection

• Virtual envs — reproducible environments

• Git integration — visual diffs, branch switching

"The tool got smarter, but YOU still write every line."

Era 4: Stack Overflow (2008-2023)

The real workflow:

• Google: "matplotlib two y-axes same plot"

• Click first SO result (450K views)

• Copy the accepted answer

• Paste, change variable names

• Pray it works

• If not, try the second answer

"Someone already solved it — you just need to find it."

The irony of Era 4: Charts got better (copied from better examples), but time got worse — 45 min coding, 2 hours on Stack Overflow

AI Changes Everything

Era 5: ChatGPT (Late 2022-present)

Describe WHAT you want. AI writes HOW.

The Prompt (15 seconds)
"I have a CSV with columns: date, channel,
impressions, clicks, conversions, spend,
revenue.

Write a Python script that:
1. Loads and shows basic statistics
2. Bar chart of spend vs revenue
3. Monthly revenue trend
4. ROI and CTR per channel
Use pandas + matplotlib."

→ Complete working script. First try.
→ 105 lines of clean, professional code.

Era 7: The Agentic Era (2025-present)

Claude Code — AI as Your Builder

What makes this different from ChatGPT or Cursor:

• Reads your files, data, and project structure

• Writes code across multiple files at once

• Runs the code and reads the output

• Iterates — fixes errors, adjusts, retries

• End-to-end — from idea to working project

• You are the architect, AI is the builder
